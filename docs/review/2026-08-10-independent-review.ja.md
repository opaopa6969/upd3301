## P0: 決定論契約が main で破れていた（修正済み `82da81c`）

**レビューで最も重い指摘であり、作業者の自己評価に一切出てこなかった項目。**

`bd06d2f`（8255アクセスをサブCPUとの同期点にする、#32 iter.3）で導入した `_syncSub()` の時計
`_subMark` / `_subDebt` が `snapshot()` / `restore()` に含まれていなかった。restore 後、
分岐前タイムラインのサブCPU残債が持ち越され、**同一入力でも別の状態に着地する**。

```
node --test   313件中1件 fail（test-snapshot.mjs:63
              「pc8801: snapshot/restore with sub board and mounted disk」）
```

`bd06d2f` 以降 HEAD まで全コミットで fail。この状態の PR #35 が main にマージ済みだった。
巻き戻し・ジョグシャトル・ICE の分岐ツリーは全部この契約の上に載っている。
さらに `docs/ice-design.md` の「verified by test-snapshot.mjs」が**その時点で虚偽**になっていた。

### なぜ2日間気付かなかったか

走行中の回帰確認を毎回 `node test.mjs`（CRTC単体63件）で済ませ、`node --test`（313件）を
回していなかった。**test-snapshot.mjs は ROM が要るテストだが、このマシンには ROM があるので
ちゃんと落ちて教えていた。検出器はあったのに、網にかけていなかった。**

### これが自己評価への最大の反証

作業者は「**作る道具は良いが、測る道具が甘い**」と総括していた。レビューの反論:

> 甘いのは道具ではなく**規律**。指標の3連続ミス（250f固定 / display mask / GVRAM）は
> むしろ「指標を疑い、直し、教訓を文書化する」ループが機能している証拠。一方で
> **既にある決定論テストを回帰網から外して broken main を push した**ことは、
> どんな測定器を追加しても防げない種類の失敗であり、総括はこれを完全に見落としている。
> 処方箋は「もっと良い指標」ではなく「CI と、回すテストセットの固定」。

## 論点別の評価

### 1機種 → 6機種の拡大は正しかったか

**技術判断としては正しかった。ただし「拡大」は未完で、いま積み上がっているのは機種ではなく統合負債。**

正しかった根拠:

- 再利用の主張が本物だった。`m68000.js` は SingleStepTests 261,894/261,894（状態一致100%、
  アドレスエラー除く）で検証され、**メガドライブと X68000 で一行も変更なしに**実戦投入された。
  `upd765.js` も X68000 で無改造。「機種を足すコスト＝そのチップを書くだけ」という仮説は実証された
- **検証の質が PC-8801 より上がった機種すらある**。NES は nestest 8991/8991行一致、
  `cpu_interrupts_v2` 5/5 ── M88 という「たまに間違う gold」より遥かに強い神託で殴っている
- PC-8801 深掘りの限界も既に見えていた。残り13本は JIKO_PZL・Yaksa に4イテレーション使って
  真因未到達。**「PC-8801 を深く仕上げる方が価値が高かった」という対立仮説は、
  収穫逓減曲線を見る限り支持できない**

危うい点:

1. **統合されていない拡大は拡大ではない。** 5ブランチ約73,000行が main 未マージで、
   **全ブランチが `demo/machine.html` を独立に +135〜+451行ずつ改変**している。
   放置するほどコンフリクトが複利で増える。**main しか見ない人には、今も1機種エミュ**
2. **検証の質に大きな非対称。** NES(強) / X68000(中、ただし「ok」の多くは Human68k の
   プロンプト画面でありゲームプレイではない) / MD(中、市販ROMゼロ) /
   **PCE(薄、1169本あるのにスイープ数字の報告なし) / PC-9801(最薄、手元 ITF が386用で
   V30コアでは実ROM起動不能)**。「薄く広がった」批判はコアには当たらないが、
   **PCE と PC-98 には当たる**
3. **Seta(#36) は issue だけで中身が無い。** 7機種目の前に5機種を main に戻すのが先

### 未検証の積み上がり

- **ブラウザ実描画は全6機種で一度も人間の目を通っていない。** PC-8801 ですら
  「headless の fingerprint が M88 と一致」であって「画面が正しい」ではない。
  crt.js/tube.js という看板は、6機種分の新画面出力と組み合わせて一度も検証されていない
- **audio は実スピーカーで全機種未検証**
- **「ok」の意味が機種ごとに違う。** X68=起動プロンプト、MD=homebrew が描画、
  NES=テストROM判定バイト。**横並びの数字に見えて測っている深さが揃っていない**
- 未検証が一番濃いのは実は**ホスト層**（`demo/machine.html`）
